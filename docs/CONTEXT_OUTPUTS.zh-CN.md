# 大输出与上下文指标（alpha.14）

成功完成的原生 exec_command / write_stdin 结果超过 12,000 字符时，Harness 将收到的完整结果保存到配置目录的 output-artifacts/<sha256>.txt，网页获得原生状态头、2,400 字符预览和文件位置。Agent 可通过已有原生文件工具按行或字符范围展开。没有新增 MCP 工具，不需要变更连接器身份。

原始 Codex 会话记录不修改。网页实时结果与后续有工具权限的历史重建使用同一预览。失败结果、仍在运行的任务、第三方工具、图片保持原样。只读模式与正式压缩请求保留原始证据，避免依赖无法调用的读取工具。

文件保存的是**收到的结果**：如果原生工具已经截断输出，文件也只有截断后的内容。应在执行端将预计很大的结果直接写入任务产物，再打印需要的字段。不要为了拿到已有输出重新执行实验。

文件名哈希覆盖完整结果；相同结果复用文件，变化产生新版本。这不是源文件读取缓存，更不是命令执行缓存；不证明原始文件目前仍未变化。引用应保留路径与哈希，读取范围由 Agent 自行选择。

目录默认 0700、文件 0600；总量到 256 MiB 后新结果回退完整返回，不自动删除已有引用。存储失败、文件损坏或符号链接目标同样回退原始结果。清理需先确认不存在会话或检查点依赖。

日志新增 context_submission（预备提交文本字节数、分段数、retained 命中）和 context_accounting（完整模型表示估算 token、原始工具结果字符数、条目数、估算耗时）。两者都不是 OpenAI 实际计费用量；预备提交不表示网络已经成功接收。日志不包含结果正文或令牌。

Token 计数增加最多 2,048 项的哈希缓存，仅保存摘要和计数，不保存原文。没有减少实际上下文预留、扩大窗口、修改安全校验或开启实验性工具批处理。

离线样本：原研究 45 个工具结果中 22 个变为预览，结果部分从 220,165 降至 49,427 估算 token，约减少 77.6%。这不是整体 token、实验时间或策略质量的实测提升；按需展开会增加用量。

尚未实施：源文件范围自动失效缓存、公开状态历史删减、MCP 双表示删减。这些仍需消费端证据，避免错误复用旧文件或丢失有效信息。
